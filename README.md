# NOVA - AI Productivity Platform Landing Page

A modern, fully responsive SaaS landing page built for the fictional company **NOVA** (AI Productivity Platform). Developed to demonstrate front-end development, UI/UX design, component architecture, and responsive layouts[cite: 1].

## 🚀 Live Demo
- **Live Website URL:** [https://nova-ai-productivity-platform.ai.studio](https://nova-ai-productivity-platform.ai.studio)[cite: 1]

## 🛠️ Technologies Used
- **React** & **Vite** - Fast component-driven architecture[cite: 1]
- **Tailwind CSS** - Utility-first styling and fully responsive design[cite: 1]
- **JavaScript (ES6+)** - State management and interactive features[cite: 1]
- **Google AI Studio** - AI-assisted development and scaffolding[cite: 1]
